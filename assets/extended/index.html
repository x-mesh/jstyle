      04 / PROBLEM STAIRS

      문제 제기 카드 계단

      "왜 제대로 되지 못할까요?" 같은 질문 제목 아래 번호 카드 네 장을 위아래로 엇갈려 놓습니다. 위아래 가는 선이 섹션을 이어 줍니다.

      우리 팀의 일정 관리,
      왜 매번 어긋날까요?

      1. 담당자 한 사람의 기억에 의존하는 운영
      2. 수기로 옮겨 적는 일이 많은 업무 방식
      3. 반복되는 단순 확인 요청의 과부하
      4. 여러 도구에 흩어진 팀 정보

      05 / SCROLL REVEAL

      스크롤 따라 밝아지는 문단

      12 / THREE PILLARS

      세 기둥 카드와 강조 문장

      어두운 카드 세 장에 선 아이콘과 긴 설명만 둡니다. 카드 바탕은 흰색 4%, 테두리는 흰색 8%입니다. 이어지는 마무리 문장에서 핵심어 하나만 초록으로 칠합니다.

      • 팀, 구성원, 목표, 회의 기록, 승인 문서처럼 구조적으로 쌓인 데이터가 작업 공간의 기억을 이룹니다.

      • 외부 도구와의 연동 데이터와 팀 문서가 이어지면 관계와 맥락을 아는 작업 공간이 완성됩니다.

      • 데스크톱 앱에 개인 파일을 연결하면 각자의 업무 맥락을 아는 나만의 보조가 됩니다.

      바로 알고, 이미 알고, 모두 아는 작업 공간.
