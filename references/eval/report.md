# 보고서 양식

사용자 언어로 쓰고 사이트의 글은 원래 언어로 인용합니다.
모드에 해당하지 않는 절(`quick`의 과제·스타일 목록 등)은 빼고 확인 범위에 그렇게 적습니다.

````markdown
# <사이트> — 사이트 평가

| | |
|---|---|
| 날짜 | YYYY-MM-DD |
| 모드 | quick / site / app |
| 범위 | 소유 · 허락 · 보기만(남의 사이트) |
| 주소 | <url> |
| 페이지 | 본 것 <n> / 찾은 것 <n> · 전환 페이지: <목록> |
| 너비 | <쓴 너비 묶음> · 첫 화면 1440×900 / 375×812 |
| 브라우저 | <도구> · 기기 흉내: 휴대폰 / 너비만 바꿈 · 어두운 모드: 봄 / 없음 |
| 속도 제한 | 없음 / 느린 4G + CPU 4배 |
| 사용자 | <역할, 기기, 인내심, 사전 지식> |
| 정한 기본값 | <quick 모드에서 묻지 않은 것> |

```

발견    Critical 0 · High 2 · Medium 5 · Low 3 · (측정 6 · 관찰 3 · 판단 1)

빈곳    <빠진 필수 근거, 없으면 "없음">
```
````
