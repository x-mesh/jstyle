# 컴포넌트 집중 개선

먼저 컴포넌트의 대상, 사용자의 주 동작, 필요한 상태와 실제 콘텐츠 길이를 정합니다.
하나의 시각적 특징에 집중하고 나머지는 기존 토큰을 따릅니다. 모든 카드에 다른 장식을 넣지 않습니다.
기존 컴포넌트가 있으면 변형을 확장하고 새 라이브러리를 추가하지 않습니다.

## 독자 카드 패턴 25개

실행 가능한 코드는 [패턴 라이브러리](../../assets/extended/index.html)에 있습니다.
각 article의 id는 아래 번호와 대응합니다. 공통 CSS와 필요한 이벤트 핸들러만 함께 옮깁니다.
예제의 데이터와 수치는 모의 콘텐츠이며 서버나 영구 저장소에 연결되지 않습니다.

1. editorial: 읽기 중심의 제목과 본문.
2. metric: 단위와 기준 기간이 있는 수치.
3. trend: 수치 표가 동반된 추세.
4. task: 완료 상태를 바꾸는 작업.
5. profile: 대상과 역할을 보여 주는 인물.
6. plan: 라디오로 하나만 선택하는 요금안.
7. event: 날짜와 위치가 있는 일정.
8. file: 실제 파일 링크가 있는 자산.
9. activity: 시간 순서가 있는 변경 기록.
10. quote: 출처가 있는 인용.
11. comparison: 항목별 차이를 보여 주는 비교.
12. progress: 현재 값과 목표가 있는 진행률.
13. alert: 원인과 다음 동작이 있는 알림.
14. empty: 다음 작업을 안내하는 빈 상태.
15. disclosure: native details로 펼치는 추가 정보.
16. drawer: 카드 내부에서 열고 닫는 상세 영역.
17. dialog: 포커스를 제한하는 확장 대화상자.
18. form: 확인과 결과 안내가 있는 입력.
19. state: 로딩·실패·재시도가 있는 비동기 경로.
20. tabs: 방향키·Home·End를 지원하는 탭 전환.
21. quantity: 상한·하한과 비활성 버튼이 있는 인원 조절.
22. assignee: 이름·역할 검색과 빈 결과를 제공하는 목록.
23. preferences: 켜짐·꺼짐과 설명을 연결하는 알림 스위치.
24. undo: 보관 후 초점을 유지하며 되돌리는 작업.
25. tags: 선택 목록과 개수를 알려 주는 다중 선택.

## 펼침 선택

짧은 보조 정보는 details, 같은 객체의 속성은 인라인 패널, 별도 작업은 dialog를 사용합니다.
펼침 전후에 제목과 호출 버튼의 위치를 추적할 수 있어야 합니다.
필요한 높이는 콘텐츠로 정합니다. 긴 내용을 고정 높이로 자르지 않습니다.
표시 상태와 aria-expanded, aria-controls를 일치시킵니다. 닫힌 영역은 포커스 순서에서 빠져야 합니다.
닫으면 초점이 사라지지 않게 합니다. 접힘·열림을 색상에만 의존하지 않습니다.
전환 애니메이션은 선택 사항입니다. reduced-motion과 키보드 동작을 먼저 보장합니다.
