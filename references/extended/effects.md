# 절제된 효과

효과가 정보, 공간 관계 또는 제품 정체성을 돕는 위치를 먼저 정합니다.
정보 전달에 필요하지 않으면 제거할 수 있어야 합니다. 본문 대비와 조작 영역을 보호합니다.
[실행 예제](../../assets/extended/index.html#effects)는 빛 궤적·점 파동·오로라·스포트라이트·동심원·빛줄기와 시작 효과 3종을 제공합니다.

## 만들기 선택

빛 궤적은 가상 요소의 transform과 opacity로 제한합니다. 큰 영역의 blur를 계속 다시 그리지 않습니다.
점 패턴은 CSS radial-gradient를 사용합니다. 점 하나마다 DOM 노드를 추가하지 않습니다.
흐르는 그라디언트는 별도 장식 레이어에서 이동합니다. 실제 콘텐츠와 레이어를 분리합니다.
효과 레이어는 pointer-events: none과 aria-hidden을 사용합니다. 정보나 조작을 장식 레이어에 넣지 않습니다.
WebGL은 CSS·SVG로 표현할 수 없을 때만 살펴봅니다. 컨텍스트 손실 시 정적 화면과 상태 안내를 제공합니다.

## 동작과 성능

기본 예제는 정지 상태입니다. 명시적 재생·정지 제어가 있을 때만 반복 동작을 켭니다.
prefers-reduced-motion에서는 이동을 없애고 정적 대비를 유지합니다.
화면 밖이나 숨겨진 탭의 작업은 중단합니다. 이벤트와 렌더 루프는 해제합니다.
저사양 장치에서 실제 프레임과 입력 지연을 측정한 경우에만 성능 수치를 보고합니다.
효과가 없을 때와 강제 색상 모드에서도 콘텐츠가 읽히는지 확인합니다.

## 시작 효과

순차 등장은 읽는 순서에 따라 카드를 보여 줍니다. 커튼 열기는 덮개만 걷어냅니다.
문장 드러내기는 각 줄의 경계 안에서 텍스트를 올립니다.
세 효과는 한 번 재생한 뒤 멈춥니다. 완료 상태와 다시 재생·처음부터 버튼을 제공합니다.
제품에서는 첫 진입에만 실행하고, 일반 상태 갱신마다 반복하지 않습니다.
재생 전과 동작 감소 설정에서는 완성 상태를 보여 줍니다. 핵심 정보에 접근하기 위해 재생을 강요하지 않습니다.
코드 보기는 선택한 효과와 속도를 반영하며 독립 HTML로 복사할 수 있습니다.
