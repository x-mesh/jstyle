# 미니게임 상태와 피드백

이 지침은 기본 [게임 설계](../play.md)에 상태·입력·복구 확인을 추가합니다.
게임 규칙, 승패 조건, 세션 데이터와 영구 데이터를 먼저 분리합니다.

## 상태 모델

ready → playing → paused → playing, playing → won/lost, won/lost → ready 전이를 명시합니다.
각 상태에서 허용된 입력만 처리합니다. 종료 뒤 입력이 점수나 보상을 바꾸면 실패입니다.
시간은 프레임 수가 아닌 경과 시간으로 계산합니다. 중단 후 복귀에서 거대한 시간 차를 그대로 적용하지 않습니다.
탭이 숨겨지면 일시정지하고 복귀 후 사용자가 재개할 수 있게 합니다.
재시작은 타이머·이벤트·객체를 초기화합니다. 중복 루프를 만들지 않습니다.

## 입력과 표현

키보드와 터치로 핵심 동작이 가능합니다. 페이지 전체의 키 입력을 무조건 차단하지 않습니다.
점수 변화, 실패 원인, 남은 횟수를 텍스트로도 표현합니다. 소리와 색만으로 결과를 알리지 않습니다.
시각 효과보다 입력 판정과 결과를 먼저 연결합니다. 동작 감소 설정에서도 규칙은 같습니다.
반복 점멸을 피합니다. 시간 제한 완화가 게임 규칙을 해치지 않으면 제공합니다.

## 확인

고정된 입력으로 시작·정지·재개·승리·실패·재시작을 실행합니다.
연속 재시작, 탭 전환, 좁은 화면, 입력 연타를 확인합니다.
저장이 있으면 실제 새로고침 후 읽기와 저장 실패를 확인합니다.
확률 보상이나 결제가 실제 서비스와 연결되지 않았다면 문서에 그 경계를 명시합니다.
