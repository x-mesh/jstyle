# 살펴보고 고치기

읽기 전용 요청에는 발견 사항과 근거만 반환합니다. 아래 고침 루프는 만들기·개선 요청에만 적용합니다.
독립 살펴보는 사람는 실행 권한과 도구가 있을 때만 사용합니다. 없으면 직접 살펴보기하고 별도 살펴보기는 하지 않았다고 밝힙니다.
9/10은 디자인 목표이며 품질 인증이 아닙니다. 실제 화면을 보지 않았으면 시각 점수를 내지 않습니다.

## 첫 살펴보기

사용자의 원래 작업과 제약, 현재 화면, 실행 가능한 주소를 기준으로 판단합니다.
시각 계층, 가독성, 일관성, 상태 피드백, 작업 완료 가능성을 각각 확인합니다.
결함마다 화면·조작·관찰 결과·영향·고침 방향을 남깁니다. 취향과 동작 결함을 구분합니다.
작업 실패·데이터 손실·키보드 차단을 장식 문제보다 먼저 고칩니다.

## 위험을 겨냥한 확인

상태가 많은 경로에서 해당 위험을 고릅니다. 모든 작업에 같은 대형 점검표를 적용하지 않습니다.
저장은 실패·중복 제출·새로고침 후 읽기를 확인합니다.
버튼이나 불러오기 뒤에 나타나는 폼·대화상자는 불러오는 중·불러온 뒤·선택·저장 성공·저장 실패·다시 불러오기와 좁은 화면에서 배치를 확인합니다. 첫 화면만 보고 이 상태들을 통과로 치지 않습니다.
검색은 느린 이전 응답·빈 결과·필터 해제를 확인합니다.
상세 패널은 긴 콘텐츠·좁은 화면·닫기 후 포커스를 확인합니다.
권한은 금지 동작과 실제 서버 거절을 확인합니다. 화면에서 숨긴 것만으로 권한 확인을 통과하지 않습니다.

## 고침과 재확인

동작을 막는 문제부터 고치고 같은 입력과 경로를 다시 실행합니다.
변경한 공통 요소의 종속 화면도 확인합니다. 바뀌지 않은 증거는 재사용합니다.
기본 최대 3회 살펴보기합니다. 작업이 끝나지 않았으면 미해결 항목을 명시하고 완료라고 하지 않습니다.
같은 고침이 두 번 실패하면 원인을 다시 확인합니다. 점수를 올리려고 장식을 반복 추가하지 않습니다.
새 정보로 방향 자체가 틀렸음이 드러나면 고침 범위와 근거를 설명합니다.

## 마감

불필요한 상자·구분선·배지·중복 설명을 제거합니다. 실제 의미가 있는 강조만 남깁니다.
본문 크기, 대비, 키보드 포커스, 긴 문구, 200% 확대와 좁은 화면을 확인합니다.
변경 범위, 실행한 검사, 미확인 동작, 남은 결함과 증거 경로를 보고합니다.
설명·살펴보기만으로 실제 사용성 확인을 했다고 보고하지 않습니다.
