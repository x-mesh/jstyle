# 대시보드와 작업 도구

작업 대상과 사용 빈도로 구조를 정합니다. 모든 제품을 통계 카드 네 개와 차트로 시작하지 않습니다.

## 구조 선택

여러 항목을 빠르게 처리하면 목록과 상세 패널을 사용합니다. 선택 항목과 목록 위치를 유지합니다.
공간이나 시간 관계가 핵심이면 캔버스 또는 타임라인을 중심에 둡니다. 확대·축소 외의 탐색도 제공합니다.
작성·편집이 핵심이면 문서나 작업물을 가장 넓게 두고 속성·도구를 보조 패널에 둡니다.
운영 판단이 핵심이면 예외·미처리 작업을 먼저 보여 줍니다. 지표는 기간·단위·근거와 연결합니다.
대시보드 지표를 임의로 만들지 않습니다. 모의 데이터는 문서에서 구분합니다.

## 조작과 밀도

검색, 필터, 정렬, 일괄 동작의 범위를 분명히 합니다. 현재 페이지 선택과 전체 결과 선택을 구분합니다.
필터 결과가 비면 조건을 유지하고 초기화 동작을 제공합니다.
행의 주 동작과 선택 체크박스를 분리합니다. 행 안 버튼이 행 탐색까지 실행되지 않게 합니다.
상세 패널은 좁은 화면에서 별도 화면이나 대화상자로 바뀝니다. 뒤로 가면 선택과 위치를 복원합니다.
표의 단위·숫자 정렬·헤더를 일관되게 유지합니다. 작은 글씨로 밀도를 해결하지 않습니다.
오래된 데이터는 최신 데이터처럼 표시하지 않습니다. 갱신 실패와 마지막 성공 시각을 알려 줍니다.

## 확인

빈 데이터, 긴 이름, 많은 행, 권한이 다른 사용자, 좁은 화면을 실제 콘텐츠로 확인합니다.
핵심 작업에 필요한 정보가 첫 화면에서 보이는지 확인합니다. 장식용 요약은 그 뒤에 둡니다.
