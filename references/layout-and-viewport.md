# 화면 배치와 크기

## 참고 화면을 따라 만들기

참고 그림의 화면 크기, 픽셀 수, 전체 범위, 고정된 부분부터 적습니다.
이미지 픽셀 수와 CSS 화면 크기는 다릅니다. 2배 이미지라면 크기를 2로 나눕니다. 알 수 없으면 어떤 가정을 썼는지 적습니다.
큰 영역의 너비 비율, 맞춤선, 색과 글자 크기의 차이를 먼저 맞춥니다. 그다음 테두리·그림자·작은 부분을 다듬습니다.
이 작업에서 새 스타일을 다시 찾지 않습니다.

긴 참고 그림은 위아래 여백을 줄여 놓았을 수 있습니다. 작은 글자에 깨진 글자나 임시 문구가 섞여 있는지도 살펴봅니다.
세로 픽셀 좌표만 그대로 따라 그리지 않습니다. 실제 웹페이지에서 읽기 좋은 여백으로 풀어 줍니다.
예를 들어 넓은 화면의 블록은 `padding-block: clamp(88px, 9vw, 136px)`부터 검토할 수 있습니다.
작업 도구에서는 쓸모없는 바깥 창 장식을 빼고 카드 안쪽 여백을 유지합니다.
글의 뜻과 크기 차이는 지키면서 사용자의 언어로 자연스럽게 고칩니다. 깨진 글자와 임시 문구는 남기지 않습니다.
매번 실제 화면과 참고 그림을 직접 나란히 봅니다. `--compare`의 픽셀 차이로 디자인을 대신 판단하지 않습니다.
작은 화면과 필요한 동작 상태도 확인합니다.

## 다른 크기의 화면

한 기기나 고정된 크기를 지정했다면 그 범위를 확인합니다.
그 밖에는 주로 쓰는 크기에서 핵심 작업을 끝까지 해 본 뒤, 다른 크기에서 대표 상태를 봅니다.
두 기기에서 같은 흐름을 끝내야 할 때만 전체 경로를 두 번 걷습니다.
본문을 실제 크기로 읽고, 주된 버튼이 보이며 눌리는지, 글이 넘치거나 가려지는지 살펴봅니다.
문제를 찾으면 같은 크기에서 고친 뒤 다시 봅니다. 캡처를 더 찍는 것으로 수정을 대신하지 않습니다.

긴 내용, 빈 내용, 오류와 복구, 바뀐 부분 중 화면을 가장 크게 흔들 위험 하나를 더 확인합니다.
이미 대표 상태에 들어 있으면 거듭 찍지 않습니다. 언어·페이지·상태의 모든 조합을 무조건 확인하지 않습니다.
실제로 배치나 동작이 달라지는 조합 가운데 위험이 큰 것만 더 봅니다.

추가 확인이 필요한 경우는 다음과 같습니다.

- Canvas나 손짓 입력: 한 번 그리거나 끌어 보고, 좌표와 손의 움직임이 맞는지 봅니다.
- 여러 열: 작은 화면에서 읽는 순서, 조작 순서, 각 열의 스크롤을 살펴봅니다.
- 팝업과 키보드: 입력창에 초점을 두고 닫기와 주된 버튼이 가려지지 않는지 봅니다.
- 여러 화면의 앱: 두 화면 이상 이동한 뒤 돌아와 현재 위치와 선택이 이어지는지 봅니다.
- 안쪽 스크롤: 페이지와 안쪽 영역을 각각 움직여 이중 스크롤이나 멈춤이 없는지 봅니다.
- 특수 화면: 지정 크기, 가로·세로 바꾸기, 안전 여백, 확대, 높이 변화가 결과에 영향을 줄 때만 더 봅니다.
