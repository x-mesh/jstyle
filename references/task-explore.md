# 여러 방향을 비교할 때

[스킬 본문](../SKILL.md)이나 사용자가 방향·변경 폭·배치를 비교해 달라고 했을 때만 이 흐름을 더합니다.
기본 작업의 사용자 사실, 바꿀 수 없는 범위, 만들기와 확인 절차는 그대로 지킵니다.
사용자가 개수를 정하지 않았다면 셋을 기본으로 봅니다.
변경 폭을 비교하면 기존 화면을 남기고, 배치만 비교하면 글꼴·색·버튼 규칙은 유지합니다.
안에서 생각할 개념·스케치·이미지의 수까지 겉으로 보일 개수에 맞춰 줄이지 않습니다.

먼저 각 방향의 느낌, 첫 화면, 주된 동작, 글꼴·색·중심 그림을 3~4줄로 설명하고 추천하는 까닭을 적습니다.
사용자가 글만 보고 고를 수 있으면 고른 하나만 만듭니다. 실제로 비교하고 싶어 할 때만 여러 첫 화면을 만듭니다.
설명만 부탁했다면 여기서 끝내고 실제 화면을 그리지 않았다고 밝힙니다.
이미 정한 스타일이나 참고 그림이 있으면 그 안에서 뼈대와 중심 그림을 달리합니다.

## 실제 화면으로 비교하기

[비교 화면](style-explorer.md)에 안마다 HTML 하나, 화면 크기 하나, 첫 화면과 주된 상태만 넣습니다.
방향을 고르기 전에 전체 페이지·실제 동작·반응형·움직임을 모두 만들지 않습니다.
공유할 제품 사실과 예시 자료는 한 번만 씁니다. 구조·스타일·제목·중심 그림은 안마다 따로 만듭니다.
이미지 중심 안은 [이미지와 자료](media.md)에 따라 한 장을 만들고 최대 한 번 다시 만듭니다.
다른 이미지 자리는 화면에서 뽑은 색으로 채워 둡니다.
한꺼번에 축소 캡처와 나란히 보기 자료를 만들고, 겹침·잘림·뚜렷한 거침만 고친 뒤 보여 줍니다.
서로 다른 사람이 만들도록 허용됐다면 공유 파일을 동시에 바꾸지 않게 나눕니다.

사용자에게 어떤 부분이 좋고 싫은지와 고를 안을 물은 뒤 멈춥니다.
바로 하라고 했거나 사람이 없는 자동 작업이면 스스로 고르되, 너비 480px로 나란히 보고 고른 까닭을 남깁니다.
배치만 비교할 때도 먼저 2~3개 뼈대를 글로 적고 실제 비교가 필요할 때만 첫 화면을 만듭니다.
두 방향을 합치고 싶다면 합친 첫 화면부터 보여 주고 확인받습니다.
