# 사용 흐름 살펴보기

실제 페이지나 움직이는 시안만 보고 제품을 이해합니다.
소스 코드·개발 도구·원래 작업 지시·만든 사람의 설명은 읽지 않습니다.
직접 다룰 수 없다면 정지 화면만 살펴봤다고 밝힙니다.

1. 무엇을 위한 제품이고 누가 어떤 일을 하러 올지 자신의 말로 적습니다. 미리 정해 준 사용 경로를 기다리지 않습니다.
2. 가장 중요해 보이는 작업 하나를 골라 처음부터 눈에 보이는 결과까지 실행합니다. 본 것, 고른 까닭, 일어난 일을 차례로 적습니다.
3. 더 갈 수 없었던 곳, 예상과 달라 돌아간 곳, 뜻을 짐작하느라 머뭇거린 곳을 적습니다. 기다리는 중인지, 끝났는지, 실패했는지도 가까이에서 알 수 있는지 봅니다.
4. 주된 작업에 영향을 주는 문제를 최대 3개만 적습니다. 보인 사실, 까닭으로 짐작한 것, 바라는 결과를 나눕니다. 도구의 한계인지 구분되지 않으면 아직 확인하지 못했다고 적습니다.

처음에 제품을 어떻게 이해했는지, 어떤 작업을 골랐는지, 실제 경로와 끝낸 정도를 적습니다.
그다음 중요한 문제와 확인하지 못한 것을 적습니다.
소리·진동·실제 휴대폰의 느낌을 확인하지 못했다면 통과로 표시하지 않습니다.
미적 점수나 실제 사용자의 성공률·만족도·걸리는 시간을 대신 판단하지 않습니다.
