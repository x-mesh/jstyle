# 작업 파일을 두는 곳

만드는 동안 쓰는 파일과 최종 파일을 나눕니다. `.jstyle`은 프로젝트 안의 작업 폴더입니다.
최종 파일을 두는 곳이나 별도의 디자인 규칙으로 쓰지 않습니다.

## 경로와 경계

사용자가 정한 경로나 프로젝트 규칙을 먼저 따릅니다. 이미 `_work/`나 `shots/`를 쓴다면 그대로 씁니다.
정해진 곳이 없을 때만 `.jstyle/<작업 이름>`을 만듭니다. 이름이 겹치면 뒤에 구분자를 붙이고 덮어쓰지 않습니다.
실제 코드·테스트·문서·서비스 이미지 등은 프로젝트의 정해진 위치에 둡니다.
페이지·빌드 설정·스타일·스크립트에서 `.jstyle`을 참조하지 않습니다.
비밀번호·토큰·가리지 않은 사용자 자료를 넣지 않습니다. 지난 작업을 임의로 지우거나 옮기거나 밖으로 보내지 않습니다.

## 시작하기

먼저 `AGENTS.md`, `DESIGN.md` 등 프로젝트의 규칙을 읽습니다. 없다고 작업을 멈출 필요는 없습니다.
`.jstyle`이 일반 폴더면 비우지 말고 다시 씁니다. 파일이거나 다른 곳을 가리키는 심볼릭 링크면 쓰지 않고 충돌을 알립니다.
작업마다 하위 폴더를 나누고 같은 작업을 이어갈 때만 다시 씁니다.
`.jstyle/.gitignore`가 없을 때만 다음 내용을 넣습니다.

```gitignore
*
!.gitignore
```

프로젝트 루트의 `.gitignore`는 이 과정에서 바꾸지 않습니다.
이미 다른 규칙이 있으면 원문을 지키고 작업 파일이 Git 목록에 보일 수 있음을 알립니다.
버전 관리할 자료와 문서는 정식 위치에 두며, 이를 위해 무시 규칙을 바꾸지 않습니다.

## 하위 폴더

실제로 필요할 때만 만듭니다.

- `explore/`: 아직 고르지 않은 안, 참고 자료, 스케치, 작은 시안.
- `assets/`: 원본 이미지, 중간 결과와 캐시.
- `shots/`: 스크린샷, 녹화와 살펴본 근거.
- `logs/`: 명령 기록과 임시 출력.

오래 보관할 테스트·디자인 규칙·최종 문서는 여기에 숨기지 않습니다.
아직 고르지 않은 방향이나 옮기는 도중의 기록은 이곳에 둡니다. 추측을 사용자가 정한 규칙처럼 쓰지 않습니다.

## 도구별 실행 위치

도구가 읽는 경로를 기준으로 실행 폴더를 고릅니다. 과정 출력만 작업 폴더로 모읍니다.
직접 지정한 `--out`, `--dir`, `--cache` 등은 항상 먼저 따릅니다.

- 캡처·녹화: `--root <프로젝트 루트>`와 `--out .jstyle/<작업 이름>/shots`를 지정합니다. `--root`는 서비스 범위이며 저장 폴더가 아닙니다.
- 이미지 찾기: 작업 폴더에서 `curate-media.mjs`를 실행하면 `assets/`와 `.curate-cache.json`이 그 안에 남습니다. 작업을 나눠야 하면 `--cache .curate-cache.json`도 직접 지정합니다.
- 비교 화면: `explore/`에 안을 두고 `build_explorer.py`를 실행하면 그 옆에 `style-explorer.html`이 생깁니다.
- 이미지 만들기: 최종 이미지는 `--out`으로 프로젝트의 정식 이미지 폴더에 저장합니다.
- 이미지 크기 바꾸기: 정식 `srcset`을 만들 때는 프로젝트 루트에서 `prep-image.mjs`를 실행합니다. 작업 폴더 기준의 상대 경로를 복사하지 않습니다.

자세한 선택지는 [도구](tools.md)를 따릅니다. 중간 원본은 작업 폴더에 두어도 최종 HTML은 정식 파일만 가리켜야 합니다.

## 마치기

최종 변경에 요청한 코드와 필요한 문서만 있는지 살펴봅니다.
작업 파일은 커밋에 넣지 않습니다. `.jstyle/.gitignore`는 작업 폴더 설정으로 남길 수 있습니다.
기존 무시 규칙 때문에 과정 파일이 보이면 설명하고, 숨기려고 지우거나 옮기지 않습니다.
정식 코드에 `.jstyle` 참조가 없고, 연결한 파일이 모두 존재하는지 확인합니다.
프로젝트 루트에 뜻하지 않은 캡처나 캐시가 생기지 않았는지 살펴봅니다.
최종 파일과 확인 자료의 위치를 알리고 해당 검사를 실행합니다.
기존 도구로 해결할 수 있으면 별도 폴더 관리 도구를 새로 만들지 않습니다.
